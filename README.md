# Snake Game

เกมงูแบบเรียบง่ายที่พัฒนาด้วย Python และ Tkinter

## วิธีเล่น

1. เปิดโปรแกรมเกม:

   ```bash
   python main.py
   ```

2. กดปุ่ม **Start Game** หรือกด `Enter` เพื่อเริ่มเกม
3. กินอาหารสีแดงเพื่อให้งูยาวขึ้นและได้รับคะแนน 10 คะแนนต่อชิ้น
4. หลีกเลี่ยงการชนกำแพงและชนตัวเอง
5. เมื่อจบเกม กด `Enter` เพื่อเริ่มเกมใหม่

## ปุ่มควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| ลูกศรขึ้น / `W` | เลื่อนขึ้น |
| ลูกศรลง / `S` | เลื่อนลง |
| ลูกศรซ้าย / `A` | เลื่อนซ้าย |
| ลูกศรขวา / `D` | เลื่อนขวา |
| `Space` | หยุดชั่วคราว / เล่นต่อ |
| `Enter` | เริ่มเกม / เริ่มใหม่ |
| `+` | เพิ่มความเร็ว |
| `-` | ลดความเร็ว |

นอกจากนี้ สามารถปรับความเร็วได้ผ่านแถบเลื่อน **Speed** ที่อยู่ใต้พื้นที่เกม ตั้งแต่ Slow ไปยัง Fast

## ความต้องการของระบบ

- Python 3
- Tkinter ซึ่งมาพร้อม Python บางการติดตั้งบน Windows หรือ macOS หากยังไม่มีให้ติดตั้ง Tkinter เพิ่มเติมตามระบบปฏิบัติการ
